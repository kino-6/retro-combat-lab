# retro-combat-lab

崩壊後の避難車を守りながら、周辺探索、ターン制戦闘、資源回収、車体強化、脱出行をつなげて遊ぶ軽量Webゲームです。

今回の縦スライスでは、CDDA風の「誰が、どんな状態で、何を持って危険地帯へ入るか」というリスク管理、SFC時代のローグライクRPG風UI、インクリメンタル寄りの車両拠点成長を、1画面で5〜10分ほど遊べる形にまとめています。

## ゲーム概要

プレイヤーはロサンゼルス東縁の排水路車庫を出た探索者を操作し、改造ワゴンを車両拠点にして、北東乾湖退避線まで約260km進みます。盆地は断水と火災で持たず、乾いた湖底に給水車、検疫フェンス、仮設滑走路を置いた退避線のゲートは12日目の夜明けに閉じます。

北東乾湖退避線は安全地帯ではありません。けれど、水を配れる開けた地形、車両を選別できる広さ、負傷者を一時隔離できるフェンス、外へ出る航空機が降りられる路面が残っています。そこは「助かる場所」ではなく、「次に生き延びるための列に入れる場所」です。

主な脅威はゾンビです。銃声や深追いで死者が寄ってきます。ただし、生存者、略奪者、感染動物、環境トラブルも残しており、終末世界の判断材料として扱います。

最初に探索者の経歴を選びます。元警備員、整備士、野外救護員、元配達員、元猟師、元教師で、同じ食料・資材・薬品の価値が少し変わります。

探索で資源と経験を得られますが、戦闘でHP、武器状態、弾薬、爆発物を削られすぎると翌日以降の判断が苦しくなります。探索後の戦利品はすぐには安全にならず、`車へ戻る` で積み込むまで `未積載の荷物` として残ります。

大事な判断は「もう少し奥まで漁って荷物を増やすか、今日は戻って車を進めるか」です。

連続して漁ると探索深度が上がり、報酬倍率と希少発見率が伸びます。代わりに脅威度も上がり、敵数、接敵距離、銃声で寄る敵、撤退時の損失が重くなります。日を終えると避難車は燃料を使って夜間走行し、自動で距離を進めます。燃料が切れると足止めになり、士気とHPが削られます。

危険度が高い探索先ほど、報酬倍率、希少発見率、複数敵との遭遇率が高く表示されます。安全な場所を回すだけでも生存はできますが、薬品や希少物資を狙うなら危険地帯へ踏み込む理由があります。

毎日、天候や噂によるコンディションが変わります。霧、雨、略奪者の噂、不自然な静けさなどにより、特定の探索先の危険度、必要時間、報酬、希少発見率が変動します。

道中は、郊外の逃げ道、砂漠の迂回路、検疫圏、退避線外縁へ段階的に変わります。退避線に近づくほど、同じ出口を目指す車列、検問、置き去りの物資、死者の群れが増え、探索危険度、遭遇率、走行時の摩耗が上がります。後半は走るだけでも資材や士気を削るため、補給と修理の判断が残ります。

探索先は毎回すべて表示されるのではなく、その日の周辺候補として3つだけ提示されます。車が進むほど候補の出方が変わり、序盤は道路、店舗、給油所のような拾いやすい場所が多く、中盤以降は廃診療所や封鎖検問のような重い判断を迫る場所が増えます。探索先には日替わりタグも付き、同じ場所でも報酬、時間、危険度、接敵距離が変わります。

ロケーションには調査進行度があります。探索を実行するたびに進行度が増え、最後まで漁り切ると場所ごとの確保品、強化素材、車体部品、救護棚、武器部品などを得られます。クリア済みのロケーションは以後の候補に出なくなるため、同じ封鎖検問や給油所を延々回すのではなく、道中を押さえながら前へ進む流れになります。

## 起動方法

```bash
# 依存関係インストール
npm install

# ビルド
npm run build

# ローカル起動（http://localhost:4173）
npm run start

# ロジック検証 + 自動プレイ検証
npm test

# 自動プレイ検証のみ
npm run test:autoplay
```

`index.html` が `dist/main.js` を読み込むため、先に `npm run build` を実行してください。

## 操作方法

ボタン操作とキーボード操作の両方に対応しています。画面上の各ボタンにも対応キーが表示されます。

### 車内

- **1 / 2 / 3 / 4 / 5 / 6**: ゲーム開始時は探索者の経歴を選びます。各カードには選択前プレビューが出ます。
- **1 / 2 / 3**: その日の周辺候補から探索先へ出発します。場所ごとに報酬傾向と危険度が違います。
- **Q 車体補強**: 資材を使って車体強度を上げます。夜の士気低下を抑え、移動距離も少し伸びます。
- **V 武器整備**: 資材を使って武器状態を回復します。武器が傷むと命中とダメージが落ちます。
- **W 救護棚整理**: 資材と薬品を使って回復効率を上げます。
- **E 治療**: 薬品を1つ使ってHPを大きく回復します。
- **F 食事**: 食料を1つ使ってHPと士気を少し回復します。
- **M 車を進める**: 燃料、食料、時間を使い、退避線へ十数km進みます。車体強度と野外技術が高いほど進みやすくなります。
- **K 検問を制圧 / ゲートへ抜ける**: ルート障害に到達した時、検問または退避線前の敵を正面から突破します。
- **O 迂回**: 封鎖検問のみ。燃料と時間と士気を払って戦闘を避けます。大きな物資報酬は得られません。
- **P 爆破突破**: 封鎖検問のみ。資材と爆発物を使い、戦闘なしで一部物資を回収しながら突破します。
- **D 日を終える**: 食料を消費して夜を越し、燃料があれば避難車が自動で夜間走行します。
- **X 最初から**: 最初からやり直します。

日中には残り時間があります。探索先ごとに2〜3時間を消費し、残り時間が足りない場所へは出発できません。

### 成長

探索者が経験を得てレベルアップすると、車へ帰還した時に成長方針を選びます。

- **1 近接訓練**: 攻撃と最大HPが伸び、近接命中と近接ダメージが少し上がります。
- **2 銃器運用**: 知性と弾薬が伸び、銃撃命中と銃撃ダメージが少し上がります。
- **3 野外技術**: 最大スタミナと士気が伸び、探索時の遭遇率が少し下がります。

### キャラ画像差し替え

探索者ポートレートは画像差し替えに対応しています。ゲーム画面の探索者パネルにある **画像変更** からローカル画像を選ぶと、そのブラウザの `localStorage` に保存されます。**既定に戻す** で内蔵ドット絵、または下記マニフェスト指定へ戻ります。

開発用に固定画像を使いたい場合は、`assets/portraits/portrait-manifest.json` に経歴ごとの画像パスを書いてください。

```json
{
  "guard": "assets/portraits/guard.png",
  "mechanic": "assets/portraits/mechanic.png",
  "medic": "assets/portraits/medic.png",
  "courier": "assets/portraits/courier.png",
  "hunter": "assets/portraits/hunter.png",
  "teacher": "assets/portraits/teacher.png"
}
```

推奨サイズは `160x160` または `320x320` のPNG/JPGです。未指定、または画像が読み込めない場合は、内蔵のCanvasドット絵に戻ります。

### 探索

- **廃店舗**: 食料が多め。危険度は中。
- **廃診療所**: 薬品が多め。危険度は高。
- **草に沈む道路**: 資材、弾薬、燃料が多め。比較的安全。
- **干上がった給油所**: 燃料が多め。開けた場所だが音が響きやすい。
- **封鎖検問**: 弾薬、爆発物、資材が多め。接敵距離が近く、複数敵が出やすい。

探索先カードには、報酬傾向、必要時間、接敵距離、見返り倍率、希少発見率、その日に影響しているコンディションやタグが表示されます。

探索では戦闘または3択の選択イベントが発生することがあります。箱には保存食コンテナ、医療ケース、弾薬缶、工具ロッカー、生存者の隠し箱などがあり、静かに少し取る、道具で価値を上げる、音を立てて大きく取る、のように報酬と消耗が変わります。箱以外にも、放置車両、無線ノイズ、車両異音、生存者の痕跡などが出ます。選択イベントは単純なマイナスではなく、「何を払って何を得るか」を選ぶ短い場面です。戦闘が起きなかった場合も、少量の資源を未積載の荷物として抱えます。

探索後は帰還判断になります。**C** で同じ場所をさらに漁り、**H** で資材と時間を使って探索中の応急手当を行い、**Enter** で車へ帰還します。**1 / 2 / 3** で別の探索先へ向かうこともできますが、追加探索には残り時間が必要です。車へ戻ると、探索完了報酬として場所に応じた小さな追加物資も確定し、探索深度と脅威度はリセットされます。

ロケーションを漁り切ると、レリックを得ることがあります。レリックは小さな恒久効果で、道路地図なら数手先の候補地を先読みしやすくなり、救護手順書なら治療が強くなり、弾薬ゲージなら銃撃の見積もりが安定します。

### 戦闘

- **A 攻撃 (3STA)**: 通常攻撃。近距離ほど命中しやすいです。
- **S 強攻撃 (6STA)**: 高威力。命中時に敵へ出血を付与することがあります。
- **F ハンドガン (4STA / 弾薬1)**: 中遠距離で安定します。武器状態は消耗しませんが、銃声で敵が寄ってくることがあります。
- **Y ショットガン (5STA / 弾薬2)**: 近距離の複数敵に強く、命中時に距離を押し返します。
- **N グレネード (4STA / 爆発物1)**: 複数敵をまとめて崩す非常手段です。音は大きく、使いどころが重要です。
- **L 投石 (2STA)**: 弾薬なしの牽制攻撃です。中距離で当たりやすく、まれに敵をひるませて距離を稼ぎます。
- **G ガード (2STA)**: 次に受けるダメージを軽減します。
- **B 後退 (2STA)**: 距離を伸ばし、次の攻撃に集中ボーナスを得ます。
- **R 息を整える (0STA)**: スタミナを回復しますが、敵ターンは進みます。
- **T 撤退**: HPと士気を失い、未積載の荷物の一部だけを残して撤退します。ボタンには予想HP損失、士気損失、荷物保持率が表示されます。
- **Enter 周囲を確認**: 戦闘勝利後、倒した敵と回収物を確認してから帰還判断へ進みます。

探索者には基礎ステータスと技能Lvがあります。どちらも `10` を人類の到達点に近い目安として表示します。基礎ステータスは `攻撃 / 知性 / 幸運`、技能Lvは `近接 / 銃器 / 野外` です。幸運は希少発見率に少し効きます。

戦闘ボタンには、現在の命中率とダメージ予測が表示されます。知性が高いほどダメージ予測の幅が狭くなり、判断しやすくなります。士気が高いと命中率が少し上がり、低いと命中率が落ちます。

危険な探索先では敵が2〜3体出ることがあります。攻撃対象は基本的に先頭の敵ですが、ショットガンとグレネードは複数敵を崩せます。敵は距離が届くまで攻撃できず、遠距離では詰め寄る行動が中心です。銃声で寄る敵も少し離れた位置に現れます。

銃声で寄る敵は即座に追加されず、まず路肩の死体が起き上がる予兆として表示されます。次の行動で戦闘に加わるため、撃つ、下がる、息を整えるの判断材料になります。

近接は武器状態を削る代わりに弾薬を使いません。投石は弾薬を節約できる低威力の牽制です。ハンドガンは距離を保つ武器、ショットガンは近距離の押し返し、グレネードは3体以上を打開する切り札です。

## ゲームループ

1. 朝、食料 / 資材 / 薬品 / 弾薬 / 爆発物 / 燃料 / 車体 / 士気 / HP / 残り時間を確認する
2. 必要時間と報酬を見て探索先を選ぶ
3. イベントまたは戦闘で資源と負傷リスクを受ける
4. 勝利後に、応急手当で粘るか、さらに深く漁るか、車へ戻るか選ぶ
5. 経験がたまったら、探索者の成長方針を選ぶ
6. 車内で回復、食事、車体補強、救護棚整理、移動を行う
7. ルート障害に到達したら、検問制圧、迂回、爆破突破のコストと報酬を選ぶ
8. 日を終えることで食料と燃料を消費し、夜間走行で翌日に進む
9. ゲート前の群れを抜け、退避線に滑り込むと勝利。期限、食料、HP、士気の崩壊で敗北

## 開発メモ

- LLMや将来の実装者向けの読み始めは `LLM_GUIDE.md` です。
- TypeScriptでゲームロジックとUI描画を分離しています。
- 型は `src/gameTypes.ts`、マスターデータは `src/gameData.ts`、戦闘/探索/ルート補助は各専用モジュールに分けています。
- Canvas描画は `src/sceneRenderer.ts` に分離しています。
- 資源操作は `src/resources.ts` に分離しています。
- 乱数は `src/gameUtils.ts` の `roll` と状態遷移関数の `rng` 引数を通して扱います。
- 依存ライブラリはTypeScriptのみです。
- `npm test` は固定シナリオ検証に加えて、複数シードの自動プレイで詰まりや状態破綻を確認します。
