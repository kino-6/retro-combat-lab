# retro-combat-lab

崩壊後の小拠点を守りながら、周辺探索、ターン制戦闘、資源回収、拠点強化をつなげて遊ぶ軽量Webゲームです。

今回の縦スライスでは、CDDA風の「誰が、どんな状態で、何を持って危険地帯へ入るか」というリスク管理、SFC時代のローグライクRPG風UI、インクリメンタル寄りの拠点成長を、1画面で5〜10分ほど遊べる形にまとめています。

## ゲーム概要

プレイヤーは拠点の唯一の探索者を操作し、10日目まで生き残ることを目指します。

最初に探索者の経歴を選びます。元警備員、整備士、野外救護員で、同じ食料・資材・薬品の価値が少し変わります。

探索で資源と経験を得られますが、戦闘でHP、武器状態、弾薬を削られすぎると翌日以降の判断が苦しくなります。探索後の戦利品はすぐには安全にならず、`拠点へ戻る` で持ち帰るまで `フィールドパック` に残ります。

大事な判断は「もう1回探索して荷物を増やすか、今日は戻って拠点を整えるか」です。

危険度が高い探索先ほど、報酬倍率、希少発見率、複数敵との遭遇率が高く表示されます。安全な場所を回すだけでも生存はできますが、薬品や希少物資を狙うなら危険地帯へ踏み込む理由があります。

毎日、天候や噂によるコンディションが変わります。霧、雨、略奪者の噂、不自然な静けさなどにより、特定の探索先の危険度、必要時間、報酬、希少発見率が変動します。

探索先には日替わりタグも付きます。施錠区画、火災跡、足跡多数、近道発見、開けた視界、狭い路地などにより、同じ場所でも報酬、時間、危険度、接敵距離が変わります。

## 起動方法

```bash
# 依存関係インストール
npm install

# ビルド
npm run build

# ローカル起動（http://localhost:4173）
npm run start

# ロジック検証 + 自動プレイ検証
npm test

# 自動プレイ検証のみ
npm run test:autoplay
```

`index.html` が `dist/main.js` を読み込むため、先に `npm run build` を実行してください。

## 操作方法

ボタン操作とキーボード操作の両方に対応しています。画面上の各ボタンにも対応キーが表示されます。

### 拠点

- **1 / 2 / 3**: ゲーム開始時は探索者の経歴を選びます。
- **1 / 2 / 3**: 探索先へ出発します。場所ごとに報酬傾向と危険度が違います。
- **Q 門を補強**: 資材を使って防衛力を上げます。夜の士気低下を抑えます。
- **V 武器整備**: 資材を使って武器状態を回復します。武器が傷むと命中とダメージが落ちます。
- **W 診療所改善**: 資材と薬品を使って回復効率を上げます。
- **E 治療**: 薬品を1つ使ってHPを大きく回復します。
- **F 食事**: 食料を1つ使ってHPと士気を少し回復します。
- **D 日を終える**: 食料を消費して夜を越し、日数を進めます。
- **X 最初から**: 最初からやり直します。

日中には残り時間があります。探索先ごとに2〜3時間を消費し、残り時間が足りない場所へは出発できません。

### 成長

探索者が経験を得てレベルアップすると、拠点帰還時に成長方針を選びます。

- **1 近接訓練**: 攻撃と最大HPが伸び、近接命中と近接ダメージが少し上がります。
- **2 銃器運用**: 知性と弾薬が伸び、銃撃命中と銃撃ダメージが少し上がります。
- **3 野外技術**: 最大スタミナと士気が伸び、探索時の遭遇率が少し下がります。

### 探索

- **廃店舗**: 食料が多め。危険度は中。
- **廃診療所**: 薬品が多め。危険度は高。
- **草に沈む道路**: 資材と弾薬が多め。比較的安全。

探索先カードには、報酬傾向、見返り倍率、希少発見率、出現しうる敵数、必要時間、接敵距離、その日に影響しているコンディションとタグが表示されます。

探索では戦闘または箱イベントが発生することがあります。箱には保存食コンテナ、医療ケース、弾薬缶、工具ロッカー、生存者の隠し箱などがあり、中身の傾向が違います。選択イベントは単純なマイナスではなく、「慎重に取る」「資材を使って開ける」「武器を傷めて強引に取る」「箱固有の手段を使う」のような、消耗と報酬の選択です。戦闘が起きなかった場合も、少量の資源をフィールドパックに積みます。

探索後は帰還判断になります。**C** で同じ場所をもう一度探索し、**Enter** で拠点へ帰還します。**1 / 2 / 3** で別の探索先へ向かうこともできますが、追加探索には残り時間が必要です。

### 戦闘

- **A 攻撃 (3STA)**: 通常攻撃。近距離ほど命中しやすいです。
- **S 強攻撃 (6STA)**: 高威力。命中時に敵へ出血を付与することがあります。
- **F 銃撃 (4STA / 弾薬1)**: 高命中・高威力です。武器状態は消耗しませんが、弾薬を消費し、銃声で敵が寄ってくることがあります。
- **G ガード (2STA)**: 次に受けるダメージを軽減します。
- **B 後退 (2STA)**: 距離を伸ばし、次の攻撃に集中ボーナスを得ます。
- **R 息を整える (0STA)**: スタミナを回復しますが、敵ターンは進みます。
- **T 撤退**: HPと士気を失い、フィールドパックの一部だけを残して撤退します。

戦闘ボタンには、現在の命中率とダメージ予測が表示されます。知性が高いほどダメージ予測の幅が狭くなり、判断しやすくなります。

危険な探索先では敵が2〜3体出ることがあります。攻撃対象は先頭の敵で、複数敵に囲まれるほど被弾機会が増えるため、弾薬を払って距離を保つか、近接で押し切るかの判断が重くなります。

近接は武器状態を削る代わりに弾薬を使いません。銃撃は安全な距離から強く攻撃できますが、弾薬という資源を払い、音で追加の敵を呼ぶリスクがあります。元警備員は近接寄り、整備士は弾薬と射撃運用寄りです。

## ゲームループ

1. 朝、食料 / 資材 / 薬品 / 弾薬 / 防衛 / 士気 / HP / 残り時間を確認する
2. 必要時間と報酬を見て探索先を選ぶ
3. イベントまたは戦闘で資源と負傷リスクを受ける
4. 勝利後に、さらに探索するか拠点へ戻るか選ぶ
5. 経験がたまったら、探索者の成長方針を選ぶ
6. 拠点で回復、食事、防衛強化、施設強化を行う
7. 日を終えることで食料を消費し、翌日に進む
8. 10日生存で勝利。食料、HP、士気が尽きると敗北

## 開発メモ

- TypeScriptでゲームロジックとUI描画を分離しています。
- 乱数は `roll` と状態遷移関数の `rng` 引数を通して扱います。
- 依存ライブラリはTypeScriptのみです。
- `npm test` は固定シナリオ検証に加えて、複数シードの自動プレイで詰まりや状態破綻を確認します。
